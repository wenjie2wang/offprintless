# Security Policy

## Reporting a Vulnerability

To report a security vulnerability, please use GitHub's private vulnerability reporting
(the "Report a vulnerability" button under the Security tab) at

https://github.com/wenjie2wang/offprintless/security

If your report is accepted, the vulnerability will be promptly fixed and published here:

https://github.com/wenjie2wang/offprintless/security/advisories

Your contribution is greatly appreciated. Thank you!

## Supported Versions

No bug, or vulnerability fixes are backported to previous Offprintless versions. It is the responsibility
of *Offprintless* users to stay up to date. Always use the latest version that you downloaded from here:

https://github.com/wenjie2wang/offprintless/releases/latest
